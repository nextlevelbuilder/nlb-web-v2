Gửi sản phẩm lên Directory chỉ với hai dòng lệnh — không cần rời trình soạn thảo.

npx -y @nextlevelbuilder/mcp

Hoặc kết nối MCP server vào Claude/Cursor để quản lý listing bằng ngôn ngữ tự nhiên.

Tài liệu API v1 →
~/my-product
# 1. Tạo file mô tả sản phẩm
$ npx @nextlevelbuilder/cli template developer-cli --out product.json

# 2. Gửi lên Directory
$ npx @nextlevelbuilder/cli submit product.json --api-key $NLB_API_KEY
